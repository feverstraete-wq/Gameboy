Sur iPhone : ouvrez la page dans Safari, puis « Partager → Sur l'écran d'accueil » pour l'avoir en plein écran comme une application. Le son démarre à la première pression sur un bouton ; si vous n'entendez rien, vérifiez le petit interrupteur silencieux sur la tranche du téléphone. Au clavier : flèches, X = A, Z = B, Entrée = Start, Maj = Select.

Pour charger un jeu sur iPhone : touchez « Charger une ROM », puis « Choisir un fichier » pour ouvrir l'app Fichiers. Si votre jeu est dans une archive .zip, touchez-la d'abord dans Fichiers pour l'extraire, puis sélectionnez le .gb qui en sort.

Les sauvegardes des jeux (piles de cartouche) sont conservées dans ce navigateur. Modèle émulé : Game Boy monochrome — les jeux réservés à la Game Boy Color ne démarreront pas.
